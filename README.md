# Mattel_-_Aquarius

Thumbnails for Mattel Aquarius software, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the MAME short names, as the MAME `aquarius_cart`, `aquarius_cass` software lists have them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/), scaled to 4:3 (640x480, 704x528 with the border): the snaps are taken at the machine's 320x200 (352x232) with tall pixels, so they came out squashed.
